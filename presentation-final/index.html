Why Firebase?

Outing sessions are live and constantly changing. We needed real-time, not request-response.

Real-Time Sync

WebSocket-based, sub-100ms data propagation. No polling, no REST overhead.

NoSQL by Choice

Intentional denormalization. We duplicate data to eliminate JOINs. One read loads everything.

Read-Optimized

Sessions are written once, read 1000× more. Flat schema = O(1) document fetch, every time.

Security & Privacy

We built a location app that doesn't want your location data.

12-Hour TTL

All session data auto-destructs. GPS tracking ceases the moment you arrive. Nothing is stored.

Host-Only Control

Firestore security rules enforce role-based access. Only the Host can trigger midpoint calculations.

Zero Retained GPS

No historical location data. No tracking profiles. Privacy isn't a feature, it's the architecture.
