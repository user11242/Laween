Security & Privacy

We built a location app that doesn't want your location data.

12-Hour TTL

All session data auto-destructs. GPS tracking ceases the moment you arrive. Nothing is stored.

Host-Only Control

Firestore security rules enforce role-based access. Only the Host can trigger midpoint calculations.

Zero Retained GPS

No historical location data. No tracking profiles. Privacy isn't a feature, it's the architecture.
